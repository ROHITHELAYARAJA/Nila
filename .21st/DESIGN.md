# Nila design context

A private dashboard driven by approved nightly phone conversations.

- Stack: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Radix Dialog, Supabase.
- Colors: cream canvas, ink text, lavender mood, sage schedule, peach reflection, blue hydration. Light and dark themes.
- Type: self-hosted Manrope, bold navy dashboard headings; Georgia remains on the marketing page.
- Layout: narrow desktop rail and asymmetric visual snapshot; separate compact mobile layout with bottom navigation.
- Controls: history selection, profile, nightly schedule, configuration, export and deletion. No manual wellness input or website voice agent.
- Data: owner-bound approved JSON only; missing values stay empty. Emoji visuals include text alternatives.
- Motion: original silent HyperFrames loops, scroll arrival, chart draw and bar fills; respects reduced motion and an explicit pause control.
- References and evaluated skills: docs/nila/voice-first-redesign.md.
- Current screenshot contract and shared checklist: docs/nila/hyperframes-redesign.md.
- Review: 21st deterministic checks plus Playwright and axe. Hosted catalog search required unavailable sign-in; no generated component retrieval claimed.

User-requested expressive emojis and soft rounded panels take precedence over conflicting minimalist or brutalist style constraints.
