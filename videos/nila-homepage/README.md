# NILA silent homepage loop

Independent 1920 by 1080, 30 fps, 10-second HyperFrames composition. No audio. Opening and closing poses match. Uses the original Nila lotus and purple orb. All wellness values are illustrative.

Source is generated by ../nila-launch/scripts/build.mjs. Run `npm run check`, then `npx hyperframes@0.8.155 render --quality delivery --fps 30 --output renders/nila-homepage-demo.mp4`. The website copies this output into apps/web/public/videos and uses a static poster under reduced motion.
