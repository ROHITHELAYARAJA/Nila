# Nila wellness motion

workflow: motion-graphics
flow: autonomous

## Requested result

Short, silent decorative loops for Nila's nightly wellness dashboard. Match the user's supplied pastel dashboard reference with translucent glossy spheres, a lilac crescent and cloud, and a light blue water surface. No personal information, numeric metrics or diagnostic claims appear in the rendered assets.

## Assets

Sunday coral, Monday blue, Tuesday violet, Wednesday lilac, Thursday blue, Friday orange, Saturday mint. Each sphere is 192 by 192 pixels. Aurora is 256 by 256 pixels; sleep is 192 by 192 pixels. Water-wave is 192 by 64 pixels. Four-second loops at 24 frames per second; transparent WebM and PNG fallback posters.

## Motion direction

Small, gentle rise and return with shifting reflected light. The first and final authored states agree. No flash, strobe or sound. The page supplies its own scroll reveals, reduced-motion setting and pause control. Website code supplies live user values independently of these decorative clips.

## Source and reuse

Original shapes drawn from the supplied screenshot's visual direction, not downloaded artwork. HyperFrames registry queried for glossy orb, floating sphere, moon, clouds and shimmer. Shimmer Sweep's gradient-mask concept is reused and customized; Cosmic Orb was evaluated but its full-frame WebGL treatment is too expensive for small dashboard icons. The custom vector sphere covers this gap.

## Review and export

Check compositions, inspect proof frames at 0, 1 and 3.96 seconds, open the Studio preview, then render the requested assets under the user's express instruction to create and embed HyperFrames animations. Include static fallback posters for motion-disabled playback and unsupported video decoding.
